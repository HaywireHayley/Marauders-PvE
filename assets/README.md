# assets/: our own art and data

Made for this project, not extracted from the game: loading screens (`loading/`), launcher images (`launcher/`), the
menu logo (`menu/`), minimap images (`minimap/`, with Ahtu's illustrated maps in `minimap/ahtu/`, credited in
CREDITS.md), and item data the launcher and mod read (`saves/items.json`: names, stack sizes). `female/` holds the outfit pieces the optional female build uses.
