# config/: settings the mod and launcher read

Committed defaults: `UE4SS-settings.ini` (UE4SS's own settings for offline mode), `ai_tuning.txt` (AI tuning overrides
numbers), `mods.txt` (which mods UE4SS loads). Written on your PC and not shared: `game_path.txt` (where the game is
installed), and the launcher's choices (`raid_map.txt`, `player_level.txt`, `minimap.txt`, ...).
